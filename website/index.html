Features

Everything a LaTeX document needs, in one window

  • Live preview

    The PDF updates as you type, without ever blocking the editor.

  • Two-way SyncTeX

    Jump from the source to the matching spot in the PDF, and back.

  • Works out of the box

    Uses your TeX Live, MacTeX or MiKTeX through latexmk, or the bundled Tectonic when there is none.

  • Smart completion

    For commands, environments, \ref labels, \cite keys and packages.

  • Outline, files and diagnostics

    Navigate multi-file projects and catch undefined references, missing files and duplicate labels as you type.

  • Spell checking

    In about 90 languages, detected automatically for each file.

  • Git built in

    Diffs, commits, history, branches and merge conflicts, using your own git.

  • Overleaf, offline

    Clone a project, work without a connection, Sync when you are back.

  • Coding agents

    Claude Code, Codex, Gemini CLI, Copilot and others write, rewrite and fix your document, and you review what they changed.

  • Safe by default

    A project's latexmkrc and Git configuration never run until you trust it.

Live preview

The source on one side, the page on the other

Every pause in your typing starts a build in the background: the editor never waits, and the old pages stay on screen until the new ones are ready, so nothing flashes.

Click a word in the PDF to land on its line, or jump from the cursor to the page. Errors and warnings from the log appear right where they belong in the source.

Install

Get TeXoria

Every package bundles Tectonic, so you can build right away without a TeX distribution. TeXoria then updates itself, checking each release's signature first.

macOS

In one command, into /Applications, no root needed:

curl -fsSL https://raw.githubusercontent.com/Herbrant/TeXoria/main/scripts/install.sh | sh

Or with Homebrew:

brew tap herbrant/tap && brew trust --cask herbrant/tap/texoria && brew install --cask texoria

The .dmg for Apple silicon and Intel is on the releases page. The app is not signed with an Apple Developer ID: if you copy it from the disk image yourself, run xattr -dr com.apple.quarantine /Applications/TeXoria.app once. macOS 10.15 or later.

Linux

In one command, into ~/.local, no root needed:

curl -fsSL https://raw.githubusercontent.com/Herbrant/TeXoria/main/scripts/install.sh | sh

Or with your package manager:

Arch Linux (AUR)yay -S texoria-bin
Debian, Ubuntusudo apt install ./texoria_<version>_amd64.deb
Fedora, openSUSEsudo dnf install ./texoria-<version>-1.x86_64.rpm

.deb, .rpm, AppImage and .tar.gz packages for x86_64 and aarch64 are on the releases page. Needs glibc 2.35 or later (Ubuntu 22.04, Debian 12, Fedora 36 or newer).

Windows

Download and run the installer, texoria-<version>-windows-x86_64-setup.exe, from the latest release.

The installer is not signed with a code-signing certificate, so SmartScreen may ask you to confirm: choose More info, then Run anyway.
