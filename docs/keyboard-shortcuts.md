# Keyboard shortcuts

| Action | macOS | Windows, Linux |
|---|---|---|
| Open a file or folder | ⌘O | Ctrl+O |
| Save | ⌘S | Ctrl+S |
| Export the PDF | ⇧⌘S | Ctrl+Shift+S |
| Close tab | ⌘W | Ctrl+W |
| Build | ⌘R | Ctrl+R |
| Stop the build (outside the editor) | ⌘. | Ctrl+. |
| Toggle live preview | ⌘⇧P | Ctrl+Shift+P |
| Show the cursor's position in the PDF | ⌘J | Ctrl+J |
| Jump from the PDF to the source | ⌘-click or double-click | Ctrl-click or double-click |
| Bigger / smaller editor text | ⌘= / ⌘- | Ctrl+= / Ctrl+- |
| Default editor text size | ⌘0 | Ctrl+0 |
| Zoom the PDF in / out (after clicking the preview) | ⌘= / ⌘- | Ctrl+= / Ctrl+- |
| Fit the PDF to the pane's width (after clicking the preview) | ⌘0 | Ctrl+0 |
| Fit the whole page (after clicking the preview) | ⌘9 | Ctrl+9 |
| Previous / next page (after clicking the preview) | ← / →, Page Up / Page Down | ← / →, Page Up / Page Down |
| First / last page (after clicking the preview) | Home / End | Home / End |
| Go to a page (after clicking the preview) | ⌘G | Ctrl+G |
| Outline | ⌘1 | Ctrl+1 |
| Files | ⌘⇧E | Ctrl+Shift+E |
| Source control | ⌘⇧G | Ctrl+Shift+G |
| Problems panel | ⌘⇧M | Ctrl+Shift+M |
| Agent panel | ⌘⇧K | Ctrl+Shift+K |
| Edit the selection with the agent | ⌘K | Ctrl+K |
| Send a message to the agent (⇧↵: new line) | ↵ | Enter |
| Commit (in the commit message box) | ⌘↵ | Ctrl+Enter |
| Find in the open file / replace | ⌘F / ⌥⌘F | Ctrl+F / Ctrl+H |
| Find (and replace) in the whole project | ⇧⌘F | Ctrl+Shift+F |
| Comment / uncomment the selected lines | ⌘/ | Ctrl+/ |
| Format the file (tex-fmt) | ⇧⌥F | Shift+Alt+F |
| Go to the definition (label, citation, file, command) | ⌘-click or F12 | Ctrl-click or F12 |
| Soft wrap (current tab) | ⌥Z | Alt+Z |
| Spelling corrections (code actions, in the editor) | ⌘. or right-click | Ctrl+. or right-click |
| Switch light / dark theme | ⌘⇧L | Ctrl+Shift+L |
| Settings | ⌘, | Ctrl+, |
| Quit | ⌘Q | Ctrl+Q |

In the editor, ⌘. (Ctrl+.) opens the code actions instead of stopping the run: use *Build* →
*Stop Building*, or click outside the editor first. The editor also has the usual
text-editing shortcuts (undo, redo, select all, …).
